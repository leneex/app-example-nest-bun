# NestJS on Bun

Пример приложения [NestJS](https://nestjs.com/) на рантайме [Bun](https://bun.sh/), которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `3000` |
| Путь проверки состояния | `/` |

Railpack видит `bun.lock`: ставит зависимости через Bun и запускает `bun run start`. Приложение
слушает порт из переменной окружения `PORT` — её передаёт платформа, — а без неё `3000`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
bun install

# запуск приложения
bun run start
```
